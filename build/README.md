# Listmonk CRM - Build Package

## 🚀 Server Upload Instructions

### 📦 Files to Upload:
Upload this entire `build` folder to your server.

### ⚡ Quick Start:
```bash
# On your server, run:
docker-compose up -d
```

### 🌐 Access:
- URL: `http://your-server-ip:9000`
- Create admin account on first visit

### 📋 Requirements:
- Docker & Docker Compose
- Port 9000 available
